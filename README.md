# ALL-OUT Pickleball League — Player Site

Final GitHub Pages package based on v1.85.

## Clean URL structure

- Home: `/`
- Registration: `/register/`
- Tracking: `/track/`

Each route uses a folder-level `index.html`, so public page URLs do not end in `.html`.

## Upload

Upload the **contents of this package** to the root of the GitHub repository used for the player-facing site.

Expected structure:

```text
/
├── index.html
├── register/
│   └── index.html
├── track/
│   └── index.html
├── .nojekyll
└── .gitignore
```
